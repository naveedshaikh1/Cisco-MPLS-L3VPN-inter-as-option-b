# Implementation guide

The complete implementation is now provided in [Tasks 1–4 and router commands](tasks-and-commands.md).

1. Task 1: hostnames, provider loopbacks, interface IPs and customer LAN gateways.
2. Task 2: OSPF area 0 and LDP within each provider network.
3. Task 3: internal VPNv4 BGP, customer VRFs, EIGRP/OSPF PE–CE routing and redistribution.
4. Task 4: Option B eBGP and label forwarding between R1 and R2.
5. Run [verification commands](validation.md), record actual results and save configurations.

The complete per-device files are in [configs](../configs/README.md). Use either the staged commands or the complete files. All commands are reconstructed lab candidates; actual router software and runtime behavior remain unverified.
